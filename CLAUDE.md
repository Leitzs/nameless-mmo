# CLAUDE.md

RPGTest is a PvP deathmatch RPG prototype built with Godot 4.7. The whole game is the Godot project in `godot/`;
there is nothing else to build. Its guidance (commands, conventions, architecture rules) is imported below, and
`godot/README.md` has the player-facing details and the recipes for adding content.
